## 体験の軸

1. **毎日** エコな行動の写真を 1 枚撮る → 今日の記録になり、電気・水などの資源が島に届く
2. **島で** 資源とペンギンで施設を建て、品物を作って港に届け、お魚を増やして島を広げる
3. **朝と夜** ミッションを選び、夜に振り返る → どれにでも使えるオールマイティが届く
4. **休むと氷が溶ける** — 氷が足りないと、広げた島の端から沈む (記録すれば浮かぶ)

→ ホームは「見るだけで状態がわかる」「次にやることが 1 つだけ示される」の 2 点を最優先にする。規則と数値は `docs/production-island/game-design.md`。

## 画面遷移

🟡 案:

```
                 ┌──────────── タブバー / 下部ナビ ────────────┐
                 │                                              │
  初回起動 ──▶ ホーム ◀──────────────────────────────┐          │
                 │                                    │          │
                 ├─▶ スキャン ─▶ 解析中 ─▶ 解析結果 ─▶ (すみか変化) ┘
                 │      (撮り直し / 失敗 ◀─┘)
                 ├─▶ ミッション
                 ├─▶ 記録
                 └─▶ メニュー ─▶ 図鑑 / 設定 / …
```

- スキャン〜すみか変化は**一方通行のフロー**。途中は下部ナビを隠し、左上の × で中断する (コンセプト②③と同じ)。
- 最後は必ずホームに戻る。すみか変化の見せ方は別途検討で、今は「すみかに反映」でホームに戻るだけ。

## 下部ナビゲーション

✅ **A: 5 タブ** — すみか / 記録 / **スキャン (中央・大)** / ミッション / メニュー

- よく使う画面に 1 タップで行け、「毎日開く理由」であるミッションを常に見せられる
- タブバーは全画面で共有する 1 つだけ (`Assets/UI/App/TabBar.uxml`)。すみか・記録・ミッションで表示し、スキャン〜解析結果のフローとメニューでは隠す

### 代替案 B: 3 ボタン (Sleep 型)

ペンギン / メニュー / スキャン。世界を広く見せられて迷わない一方、記録・ミッションが 2 タップになる。A で使ってみて、3D の世界が狭いと感じたら再検討する。

## 各画面に置くもの

### 1. ホーム

- **背景**: 3D の世界を全画面 (UI の後ろ)。ペンギンが中央付近に来るカメラ配置
- **上部**: 氷の量 / CO₂ 削減のステータスカード 2 枚、右上に設定
- **中央**: ペンギンの吹き出し (状態に応じて一言。「氷が減ってきたよ…」など)
- **下部の上**: 🟡 Sleep の「次の目標」にあたる**行動ボタン 1 つ** (例: 「今日のミッションを選ぶ」「夜の振り返り」「レシートを撮る」を時間帯と状態で出し分け)
- **下部**: タブバー
- ❓ 通知バッジ (未達成のミッション、新しいペンギン)

### 2. レシートスキャン

- ✅ カメラ映像、枠のガイド、シャッター (仮実装あり)
- × で閉じる、フラッシュ、ヘルプ
- 最近のスキャン (サムネイル) — ⚠️ **レシート画像は端末に保存しない方針**なので、サムネイルは出せない。日付・店の種類・CO₂e のカードに置き換える案

### 3. 解析中

- 3 段階の進み具合 (文字を読み取り中 → 商品を分類中 → CO₂ を計算中)
- ペンギンの待機アニメーション、「少しだけ待ってね…」
- 失敗時: 「読み取れなかった」→ 撮り直す / やめる

### 4. 解析結果

- 日時、店の種類
- 品目の一覧 (アイコン・カテゴリ・CO₂e)
- 合計 CO₂e を大きく、身近な例え (杉の木◯本分)
- 「すみかに反映」(強調ボタン、1 画面 1 つ)
- ❓ 品目を修正できるようにするか (AI の読み間違い対策)

### 5. すみか変化

- ⏸ 別途検討。案: (a) ホームに戻って 3D で氷が増える演出 + 結果カードを重ねる / (b) コンセプト⑤の Before/After を並べる専用画面。(b) は静止画になるので 3D の世界と二重になる点に注意

### 6. ミッション

- デイリー / ウィークリーの切り替え
- ミッションカード (アイコン、名前、進み具合、報酬 pt)
- 🟡 朝に「今日のミッションを選ぶ」、夜に「振り返る」— 選ぶ・振り返る操作をどこに置くか

### 7. 記録

- CO₂ の推移 (週の棒グラフ。Sleep のように最上部に大きく)
- 連続達成日数、エコポイント
- スキャン履歴 (明細は端末内のみ)

### 9. メニュー

- 🟡 Sleep 型: 全画面、機能をカード 2 列で並べる。閉じるボタンは下部の大きな帯
- 中身: 図鑑、記録、ミッション、設定、お知らせ、ヘルプ …

## 画面をまたぐ共通要素

- **状態**: 読み込み中 / 空 (まだ記録がない) / エラー (通信失敗・カメラ権限なし) を画面ごとに用意する
- **トースト / ダイアログ**: 保存・失敗の通知、確認
- **ペンギンの吹き出し**: ホーム以外でも案内役として使う (解析中、結果)
- **SafeArea**: ✅ `SafeAreaApplier` で対応済み
