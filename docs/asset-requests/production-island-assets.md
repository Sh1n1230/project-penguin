# 生産の島（ペンギン村）用 素材の依頼

Web 試作 `penguin-village`（Next.js、EXP-003〜EXP-006）で遊びを確かめた「生産の島」を Unity に持ってくるための素材の一覧。Codex に制作を依頼する前提で、1件ずつ「何を・どの形式で・どの大きさで・どの状態を」作るかを書く。

- 状態: 依頼前のたたき台（2026-10-07、利用者の回答を反映）。優先度は P0（最初の通しプレイに必須）→ P1（遊びの手触り）→ P2（あとで良い）。
- 出典: `penguin-village` の `design/master.md`（G-PENGUIN rev10）と各 system の設計。この文書は素材だけを扱い、ゲームの規則は書かない。
- 置き場所と命名は本リポジトリの決まりに従う（下の「納品の決まり」）。

## 2. 共通の決まり（全素材）

- **見た目**: 既存の `Cabin_Field_v001`・`Penguin_v002` と同じ、角の丸いローポリ。色は 1枚のカラーアトラスで塗る（`Cabin_ColorAtlas_v001.png` と同じ考え方）。UI の色はデザインシステムのトークン（`docs/design-system.md`）に合わせる。
- **単位**: 升目1つ＝ Unity の 1m × 1m。1×1 の建物は足元 0.9m 四方、2×2 は 1.9m 四方に収める（隣の線・ペンギンが通る隙間を残す）。高さは 1×1 が 0.6〜1.0m、2×2 が 1.0〜1.6m。
- **ピボット**: 足元の中心、Y=0 が地面。正面は -Z（カメラは手前上から見下ろす前提）。
- **ポリゴンの目安**: 1×1 は 1,500 三角形まで、2×2 は 3,000 三角形まで、床タイルは 200 まで（スマホで 100 マス＋建物 30 棟を一度に描くため）。
- **状態の見せ方**: 建物の「稼働中・停止」はモデルを差し替えず、マテリアルの切り替え（停止は彩度を下げる）と小さな動く部品で表す。動く部品は別メッシュに分け、名前に `_Anim` を付ける。
- **テクスチャ**: アトラスは 1024×1024 を基本。Normal は必要なものだけ。

## 11. 納品の決まり

- 3D モデルは `Assets/3Dmodel/<名前>_v001/` に FBX とテクスチャを置き、同じフォルダに `IMPORT_README.md` を付ける（既存の `Penguin_v002/IMPORT_README.md` と同じ書き方: 中身、テクスチャの用途、Unity での割り当て方）。
- 制作用の元データ（.blend、UV レイアウトなど）は `ArtSource/<名前>_v001/` に置き、`Assets/` には入れない。
- SVG アイコンは `Assets/UI/DesignSystem/Icons/<小文字-ハイフン>.svg`。白一色、viewBox は 0 0 24 24。
- バイナリは Git LFS の対象（`.gitattributes` に従う）。`.meta` は Unity Editor で生成し、手で書かない。
- 名前の例: `Building_Fishery_2x2_v001.fbx`、`Tile_Ice_Core_v001.fbx`、`Link_Line_v001.mat`、`Item_Kamaboko_v001.fbx`、`icon-kamaboko.svg`。

## 12. 未決（素材の依頼前に決めたいこと）

- 有向の線でつなぐ方式にしたとき、そり道（B-16、P-05）と「隣接で渡す」方式を残すか。Web 試作（EXP-007）では線に一本化してそり道を外す案を第一に検討中。外すなら作らない。
- 接続口の数・位置と線の引き方（Web 試作 EXP-007 で決める）。
- 増幅の建物の種類と見た目（Web 試作 EXP-007 で決める）。
- カメラの角度（真上か斜め上か）で、建物の正面の作り込みが変わる。
