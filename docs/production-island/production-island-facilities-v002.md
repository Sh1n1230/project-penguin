# 生産の島：施設デザイン v002

2026-10-08。ユーザーが確認したかまぼこ工場の方針を、他の施設へ展開した。完成品や用途を示す大きな屋根・目印、原料と完成品の違い、加工設備の具体的な動作、既存Penguin_v002の作業を組み合わせる。リアリティより、縮小した画面でも工程を読み取れることを優先する。

## 施設と工程

追加は20モデル・20Prefab（14施設＋港6段階）。確認済みかまぼこ工場を合わせ、レビューシーンには21項目を並べた。一次資源を生成する発電所・集水所と、未確定のそり道は今回追加しない。増幅施設の種類は依頼書の仮案に基づく表示素材で、倍率は実装していない。

## Unityで確認する

`Assets/Scenes/ProductionIslandFacilityReview.unity` を開き、Playを押す。Game画面上部の「施設を選ぶ」から施設名をクリックすると、好きな施設を直接拡大表示できる。「前へ」「次へ」も使える。「全体表示」で一覧、「停止」「再開」で工程を止めたり続けたりできる。カメラの手動操作は不要。

MCPからは `FacilityDesignGallery.Select(index)` で指定した施設へ移動できる。順番は上表のうちかまぼこを除く14施設 → 確認済みかまぼこ → 港0〜5。「次」は `Select(SelectedIndex + 1)`。

施設ごとに3〜12.8秒のループで、刻む・回す・引く・待つなどの動作と作業の間を分けた。調査した一次資料、動き、周期は [施設ごとの特徴と動き](production-island-facility-motions.md) を参照。宿舎は休息、倉庫は格納と搬出、増幅は資源トークンの図示として使う。表示専用で、生産計算・在庫・配属・接続線のルールには接続していない。

`FacilityProductionCycle.SetRunning(false/true)`、`RestartCycle()` を用意した。停止中は施設材質を低彩度へ切り替え、ペンギン・道具・原料・完成品の姿勢を維持する。ちくわには `SetHighHeat(bool)` があり、炎を強火・とろ火で変えられる。

## 負荷とデータ

新規施設本体は492〜2,336三角形、港は264〜1,836三角形。1×1は1,500以下、2×2は3,000以下、足元0.9m/1.9m以内をBlender生成時に検査する。固定部品と各可動グループを結合し、同じ名前のUVチャンネルへ統一してカラーアトラスを保つ。可動の網と魚、焼き棒とちくわは共通の親に付け、分離して動かないようにした。

各施設のカラーアトラスは同色だが、Unityの新規施設は共通のRunning/Stopped材質と漁場フォルダのアトラスを参照する。ペンギンは既存FBXの10メッシュと元の材質・画像を共用する。料理帽・作業帽を追加し、ヒレと足の親Transformを動かす。ペンギンの約38,800三角形はそのままで、複数配置の実機性能は未測定。

- 各納品フォルダ：`Assets/3Dmodel/Building_<施設>_<大きさ>_v002/`、`Assets/3Dmodel/Harbor_Stage0_v002/`〜`Harbor_Stage5_v002/`。
- 共通材質：`Assets/3Dmodel/ProductionIsland_v002/`。
- 編集用Blender：`ArtSource/<モデル名>_v002/`。
- 生成コード：`ArtSource/ProductionIsland_v002/generate_facilities.py`。
- Unity生成：`FacilityRevisionBuilder.Build()` または `Production Island > Build Facility Design Revisions`。
- 再生成時はレビューシーンを別の保存済みシーンへ切り替え、Playを止めてから実行する。
- 旧v001は比較用に残す。かまぼこ工場と元のペンギン素材の形は変更しない。

## 検証

`FacilityRevisionCapture.Start()` が通常Play Modeの異なる実フレームで工程、原料/完成品の表示順、全Transformの停止姿勢、再開始、既存ペンギン参照、網・焼き棒への子付け、道具等の変化を観測する。手動でUpdateを呼んだり工程時刻を書き換えたりしない。加工中と搬出中を撮影し、静的な港の段階とかまぼこも別途撮影する。

結果：`ArtSource/ProductionIsland_v002/Facilities/Review/motion-verification.json`。Unity 6000.6.0f1の通常Play Modeで21項目を観測し、動く15施設の固有部品の変化を含む8項目ずつ、計120項目がPASS。港0〜4は静的モデルとして別に撮影し、既に検証済みのかまぼこも参考撮影した。加工中・搬出中を含む36枚の工程画像を同フォルダへ保存した。

目視でちくわの穴と焼き色、干物網の隙間と魚の追従、仕分け所の支柱、おでんの提灯、港のいかりと舟を確認した。確認画面は既存の丸ゴシックの日本語フォントを使うUI Toolkitで、ボタン領域を避けてモデルを表示する。ボタンのクリック処理から21項目すべての直接選択、前後移動、停止/再開、全体/個別表示、一覧の開閉へ切り替わることも確認した（`ui-verification.txt`）。

新規モデルの120ファイル・フォルダと対応するmeta、生成時の20モデルの三角形数・足元寸法を検査した。Unity Consoleのコンパイル・実行エラーは0件。端末上の描画時間や大量配置時の性能、ユーザーによる新規施設それぞれのデザイン確認は未実施。
