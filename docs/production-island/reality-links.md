# 現実の行動と島のつなぎ方

生産の島の電気・水・ガス・オールマイティは、現実の行動からだけ増える (`resources.md`)。この文書は、**何を・どれだけ強く信じて・どの資源につなぐか**の考え方と、これから足す候補の優先順位をまとめる。調査 21a〜21d (2026-10-16) を、現行の実装に合わせて整理したもの。

## 原則

1. **検証が強いほど量と上限を大きく、自己申告は小さく上限付きにする。** 強さは S (センサー・業務データ) > D (書類の撮影) > P (行動の写真) > R (自己申告)。
2. **センサーは資源だけを動かし、氷 (記録日) は動かさない。** 氷は「記録の習慣」を表すので、何もしなくても育つ形にしない。記録日になるのは、写真と夜の振り返りだけ (`docs/game-logic.md`)。
3. **「やっていない」と答えても損をしない。** 自己申告は基本分に小さな上乗せ。嘘で得をしても、上限で止まる。
4. **記録の手段は問わない。** 氷の規則は「記録が 1 件あった」としか見ない (`GameSession.ScanReceipt` は写真もレシートも受ける口)。手段を足しても氷の規則は変えない。
5. **CO₂ の削減量は主張しない。** 数値を出すときは「目安」と書く。

## こじつけの対応づけ (演出の方向)

検証が弱い行動も島につなぐ。ただし**量ではなく施設の演出に寄せる**と、経済を壊さずに楽しくできる。画面には理屈をひと言だけ出し、CO₂ の数字は添えない。

| 現実のエコ行動 | 島の対応先 | ひと言 (案) |
|---|---|---|
| 冷暖房を控えた | 電気 | 消した分だけ、蓄電池の灯りが点く |
| シャワーを短くした | 水 | 短くした分、貯水槽の水位が上がる |
| 徒歩・自転車 | ガス | 燃やさなかった燃料が島の炉に回る |
| 自炊・食べ残しゼロ | さばき場・かまぼこ工場 | 魚を余すところなく使う |
| マイボトル | 水 (将来は「給水所」) | 島のペンギンもマイボトルで給水する |
| 天日干し | 干物場 | 天日で干すと干物も早く仕上がる |
| 晴れの昼に家電を回す | 電気の増幅所 | 余った太陽光を島が吸い込む |

## 規約・プライバシーとの衝突 (先に決める)

- 位置: 18b のポリシー案は「取得しません」。入れるならポリシーと同意画面の書き直しが要る。
- Core Motion・HealthKit: 5.1.3 の対象。使うならプライバシーポリシーを改訂する。
- 画像を Gemini に送る: 5.1.2(i) で、第三者の AI に個人データを渡すことの明示と同意が要る。`privacy.md` の「端末外に出してよいのは CO₂e のみ」を書き換える必要がある (写真は解析のために送るが保存しない、と)。
- 外部データの利用条件 (TEPCO・OCCTO・Open-Meteo・ODPT) は未確認のものがある。
