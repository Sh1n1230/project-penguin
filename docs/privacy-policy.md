# プライバシーポリシー (案)

2026-10-17 作成。アプリ「ペンギンの島」(開発コード名 Project Penguin、チーム ueco) が、端末のカメラと歩数をどう使うかを利用者に向けて書いたもの。App Review Guidelines 5.1.1・5.1.3 (Motion and Fitness のデータを含む) に合わせて、ストアに出す前に公開する。**まだ案で、チームとオーナーの確認前。** 実装が変わったらこの文書も直す。

## 1. 集めるもの・集めないもの

| データ | 使う目的 | 端末の外に出すか | 保存 |
|---|---|---|---|
| カメラで撮ったエコ活動の写真 (1 日 1 枚) | 写っているもの (マイボトル・消した電気など) を見分けて、島の資源にする | 判定のときだけ、写真 1 枚を当チームの判定サーバーへ送る | アプリにも判定サーバーにも保存しない (下の 2.) |
| 今日の歩数 | 歩いた歩数を島の「ガス」に変える | 送らない | 端末の中に、受け取ったガスの量だけを残す |
| 島の進み具合 (氷・施設・お魚など) と受け取りの記録 | ゲームを続けるため | 送らない | 端末の中 (SQLite) |
| 島の名前 | 画面に出すため | 送らない | 端末の中 |

- 名前・メールアドレス・位置情報・連絡先・広告用の ID は集めない。
- アカウントは無い。端末の中のデータはメニューの「データを消す」でいつでも消せる。アプリを削除しても消える。

## 2. 写真の扱い

1. アプリはカメラ映像の 1 フレームをメモリの中で画像にして、判定サーバー (当チームの backend) に送る。端末のアルバムやファイルには書かない。
2. 判定サーバーは、写真をメモリの中で Google の Gemini API に渡し、「何が写っているか」を受け取ったら写真を捨てる。ディスクにもログにも残さない。
3. **Gemini API 側での写真の扱いは、Google の利用規約とデータの取り扱いに従う。** 不正利用の監視のために、Google が入力を一定期間保持することがある。無料の利用枠では、入力が Google のサービスの改善に使われることがある。当チームはこの保持を止められないので、「どこにも残らない」とは書かない。
4. 端末に残すのは、判定の結果 (分類・写っていたものの名前) と受け取った資源の量だけ。写真そのものは残さない。
5. 人の顔や個人の情報が写らないように撮ってもらう (撮影画面での案内はまだ無い。「未決」)。

## 3. 歩数の扱い (モーションと移動のデータ)

- iOS の歩数計 (Core Motion の CMPedometer) から、**今日 (03:00 区切り) の歩数の合計だけ**を読む。経路・位置・移動の種類は読まない。HealthKit は使わない。
- 歩数は 500 歩ごとにガス 1 (1 日 20 まで) に変えるためだけに使い、**端末の外に送らない**。
- 許可の説明文: 「歩いた歩数を島のガスに変えるために、モーションと移動のデータを使います。歩数は端末の外に送りません。」(`Assets/Editor/Build/IosPostprocess.cs`)
- 許可しなくても遊べる (ガスは写真からも受け取れる)。

## 4. カメラの許可の説明文

「今日のエコな行動を撮影して、島の資源に変えるためにカメラを使います。写真はこの端末に保存しません。」(Player Settings の Camera Usage Description)

アプリ自身が保存しないことは言い切れるが、判定に使う外部サービスの保持 (2. の 3) までは言い切れないので、説明文は「この端末に」に限っている。

## 5. 子どもの利用

学校・教育機関での利用を想定している (`docs/decisions.md`)。13 歳未満の利用者がいる場合は、保護者や先生の同意のもとで使ってもらう。写真に顔を写さないよう、この文書で案内する。
