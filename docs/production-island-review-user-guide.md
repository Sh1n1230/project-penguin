# あなたがUnityで施設を確認する手順

2026-10-10更新。MCPの接続は不要です。Unityを直接操作して確認します。

## 最初に開くプロジェクト

Unity Hubから、このリポジトリのルート（`Assets`、`Packages`、`ProjectSettings`があるフォルダ）を開きます。

素材と制作元への入口は [v002一覧](production-island-v002/README.md) にまとめています。コードや素材のコピーはGitに保存せず、それぞれ元の場所を参照します。コードPRとv002素材PRの両方が必要です。v001の素材一覧は別PRです。

## 確認画面を開く

1. Unityのメインウィンドウを表示します。Game画面が独立したウィンドウになっている場合は、メインウィンドウへ切り替えます。
2. 上部の再生ボタンが青い場合は、一度押して再生を止めます。
3. **Project**ウィンドウで `Assets → Scenes → ProductionIslandFacilityReview` をダブルクリックします。検索欄に `ProductionIslandFacilityReview` と入力して探しても構いません。
4. Unity上部の **▶（再生）** を押します。
5. **Game**タブを選びます。Game内を一度クリックして、マウス入力のフォーカスを移します。
6. Game上部の **Scaleを1x** にします。以前の1.8xでは画面が拡大され、上部のボタンや一覧の端が画面外にはみ出していました。
7. 画面内の **「施設を選ぶ」→施設名** をクリックします。選んだ施設が拡大表示され、その場で工程を繰り返します。

Projectが見当たらない場合は **Window → General → Project**、Gameが見当たらない場合は **Window → General → Game** から表示します。

## ボタンの使い方

| ボタン | 操作結果 |
|---|---|
| 施設を選ぶ | 全21項目の一覧を開く。施設名をクリックして直接移動 |
| 前へ・次へ | 一つ前・次の施設を表示 |
| 全体表示 | 全施設を並べて、動きの違いを比較 |
| 個別表示 | 選んだ施設の拡大表示へ戻る |
| 停止・再開 | 工程をその姿勢で止める・続きから動かす |
| 閉じる | 施設を選ぶ一覧を閉じる |

施設を選ぶとカメラが自動で切り替わります。移動キーの操作は不要です。現在の工程は、施設名とレシピの下の青い文字で確認できます。

## 何を見るか

- 最初の一目で、屋根や大きな目印から施設の用途を判断できるか。
- 投入した物が、加工後に色・形の違う物へ変わったと読み取れるか。
- ペンギンが道具を使う、確認する、待つなど、その工程に関わって見えるか。
- 回す・引く・刻む・待つなど、施設ごとに動きと作業のリズムが違って見えるか。

港0〜4は建設段階の静的モデルです。最終段階の港では吊り上げ・納品・舟の出発を確認できます。

## Codexの確認との違い

| あなたの操作 | Codexの操作 |
|---|---|
| UnityのProjectでシーンを開き、▶で再生 | MCPやUnity CLIを通じてEditorを操作 |
| Game内のボタンを実際のマウスでクリック | 操作命令を送る、仮想マウスで検査する |
| UnityのGame画面で動きを直接見る | スクリーンショットを取得してチャットに表示する |

**チャットに表示された画像はスクリーンショットです。画像内のボタンはクリック操作できません。** 操作する場所は、UnityのGame画面です。

MCPはCodexがUnityへ操作命令を送るための接続です。あなたが手動で確認するために、MCPを起動する必要はありません。

## ボタンが反応しない場合

1. Unityが再生中で、一時停止ボタンが有効になっていないことを確認します。
2. Game画面内を一度クリックしてから、画面内の「次へ」を押します。
3. `ProductionIslandFacilityReview` を開いていることを確認します。旧 `ProductionIslandAssetCatalog` は別の確認画面です。
4. Scaleを1xに戻し、ボタン全体が画面内に見えている状態で押します。
5. それでも反応しない場合は、Codexに「手動クリックで反応しない」と伝えます。Codexから直接施設を切り替えられることだけを、マウス操作の成功とは扱いません。

2026-10-08、レビューシーンにEventSystemとInputSystemUIInputModuleを保存し、既存Input ActionsのUI操作を接続しました。シーンを開き直した後、仮想マウスの押下・解放から全50操作を確認済みです。結果は `ArtSource/ProductionIsland_v002/Facilities/Review/pointer-input-verification.txt` にあります。

2026-10-10のレビュー修正で、Input System設定の書き換えとマウスの強制有効化を削除しました。Editor用の`FacilityReviewFocus`が再生開始時にGameを開きます。必要なら **Production Island → Focus Review Game View** を選び、Game内をクリックしてください。設定アセットや入力デバイスの状態を変更しません。手動操作の最終確認は引き続き必要です。

## ファイルを探す

- `Assets/3Dmodel/`：施設v002・港6段階・かまぼこのモデルとPrefab。既存ペンギンを使用。
- `Assets/Scenes/ProductionIslandFacilityReview.unity`：v002の確認シーン。
- `Assets/Scripts/Presentation/World/`：施設の動作・表示コード。
- `ArtSource/`：Blender制作元、生成コード、工程の確認画像。
- `docs/production-island-v002/`：入口のREADMEと、元の相対パス・SHA-256を記録したmanifest。
- `scripts/package_production_island_v002.py`：ファイル一覧を更新するスクリプト。素材やコードのコピーは作りません。
