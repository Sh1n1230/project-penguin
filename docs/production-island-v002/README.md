# 生産の島・施設v002 一覧

素材、制作元、確認シーン、動作コードへの入口です。ファイルは元の場所に一つだけ保持します。

**[Unityで確認する手順](../production-island-review-user-guide.md)**

Unity Hubではこのリポジトリのルートを開き、Projectの `Assets/Scenes/ProductionIslandFacilityReview` をダブルクリックして▶を押します。
GameでScaleを1xにし、「施設を選ぶ」から名前をクリックしてください。MCPは不要です。
