# backend (FastAPI) ルール

データの扱いは `.claude/rules/privacy.md` が優先。ここは実装規約のみ。

## 構成

- `Receipt Service` — 画像バリデーション / Gemini クライアント / レスポンス JSON のバリデーション
- `Carbon Service` — カテゴリマッピング / 排出係数 / CO₂e 算出
- API キー管理

外部 LLM のレスポンスは**必ず Pydantic モデルで検証してから使う**。生の JSON をそのまま下流に流さない。

## 規約

- 型ヒントを必ず付ける。`Any` は逃げ道として使わない。
- 設定値は Pydantic Settings 等で環境変数から読む。`os.getenv` の直書きを散らさない。
- 排出係数はコードに定数として散在させず、出典を併記したデータとして一箇所にまとめる。**根拠のない係数を捏造しない。** 出典が不明なら値を仮置きせず、ユーザーに確認する。
- 例外は握りつぶさない。ただしエラーメッセージにレシートの中身を含めない。

## 依存とツール

`pyproject.toml` を正とする (パッケージマネージャは `uv` を想定)。フォーマット・Lint は `ruff`、型チェックは `mypy`、テストは `pytest`。

新しい依存を勝手に追加しない。必要な場合は理由とともに提案する。
